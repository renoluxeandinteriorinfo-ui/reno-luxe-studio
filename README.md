# Reno Luxe Studio

Build a complete, production-quality, premium MULTI-PAGE website and web application for Reno Luxe & Interior.

This is not a simple one-page landing page. Build it as a polished, fully responsive, mobile-first business website/web app with multiple connected pages, working navigation, customer accounts, product browsing, project enquiries, WhatsApp ordering, email consultation requests, portfolio browsing, and an AI interior visualization experience.

The website should feel like a premium international interior-design and décor company.

Use the functionality and user experience principles of the Foprom Foods website that I previously provided as inspiration for structure, navigation, cards, account access, mobile bottom navigation, product browsing and interactive experiences. DO NOT copy Foprom's branding, text, images, layout exactly, or visual identity. Create a completely original Reno Luxe design.
